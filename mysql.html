MySQL Tutorial

Introduction

MySQL is a popular open‑source relational database. It is used to store and retrieve structured data for web applications.

Installation

Download the MySQL Community Server from dev.mysql.com and follow the installer steps.

Verify the installation:

mysql --version

Sample Queries

Create a sample database and table:

CREATE DATABASE devtutor;
USE devtutor;
CREATE TABLE books (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    author VARCHAR(255) NOT NULL
);
INSERT INTO books (title, author) VALUES
    ('The Pragmatic Programmer', 'Andrew Hunt'),
    ('Clean Code', 'Robert C. Martin');
SELECT * FROM books;

Exercise

Extend the books table with a new column year INT, insert a few rows, and write a query that returns books published after 2010.
