JavaScript Example



JavaScript Variables

let name = "John";
const age = 20;

console.log(name);
console.log(age);

JavaScript Functions

function greet(name){

    return "Hello " + name;

}

console.log(greet("Alice"));

JavaScript Conditions

let score = 90;

if(score >= 75){

    console.log("Passed");

}else{

    console.log("Failed");

}

JavaScript Loop

for(let i=1; i<=5; i++){

    console.log(i);

}

Common JavaScript Methods

Method Description
alert() Shows a popup message
console.log() Displays output in the console
getElementById() Selects an HTML element
querySelector() Selects an element using CSS selectors
addEventListener() Adds an event listener
setTimeout() Runs code after a delay
fetch() Retrieves data from an API
JSON.parse() Converts JSON into an object
