Introduction

SQL (Structured Query Language) is the standard language for managing relational databases.

Basic Queries

Below are common SQL statements you will use:

-- SELECT all columns
SELECT * FROM employees;

-- SELECT specific columns
SELECT name, salary FROM employees;

-- INSERT a new row
INSERT INTO employees (name, role, salary) VALUES ('Alice', 'Engineer', 75000);

-- UPDATE existing rows
UPDATE employees SET salary = salary * 1.05 WHERE role = 'Engineer';

-- DELETE rows
DELETE FROM employees WHERE name = 'Bob';
